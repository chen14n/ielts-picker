# 雅思取词 IELTS Picker

> Windows 桌面划词工具，专为雅思阅读备考设计：鼠标拖选英文单词、短语或句子，黑色弹窗显示中文；单词 / 短语可收藏进 Excel，还能做同义替换配对。

- 作者：**周八拿铁**
- 版本：2.0.0
- 平台：Windows 10 / 11（64 位）
- 许可证：[MIT License](LICENSE)

## 功能特性

- **拖选即弹**：按住左键划选英文，松手后弹出结果（类似有道划词）。
- **快捷键兜底**：选中文字后按 `Ctrl+Alt+D` 取词。
- **单词 / 短语 / 句子智能区分**：单词和短语查词典；较长的句子自动走句子翻译，不再提示“找不到意思”。
- **黑色弹窗 / 大字体**：黑底白字、黑白按钮，音标 + 词性 + 中文释义。
- **自动分表收藏**：单词进「词语.xlsx」，短语进「短语.xlsx」，句子进「句子.xlsx」，同一内容不重复收藏。
- **同义替换配对**：点「同义替换」后再取一个词，自动写入「同义替换.xlsx」。
- **Excel / WPS 占用提示**：文件被占用时点收藏会提示关闭 Excel/WPS，按钮变为「重试收藏」，关掉后重试即可，无需重启程序。
- **托盘常驻**：可暂停自动划词、打开词库文件夹、退出。
- **本地缓存**：查过的内容缓存在本地，重复查询不重复请求。

## 快速开始

1. 前往 [Releases](../releases) 下载最新版 `雅思取词.exe`（仓库 `release/` 目录内也保留了一份）。
2. 把 exe 放到**桌面或较短路径**（例如 `D:\desktop`），双击运行。
   > 不要放在层级很深的目录或 OneDrive 等同步目录里，否则自解压可能失败（双击没反应）。
3. 右下角托盘出现黑白「词」图标即启动成功。首次运行会在桌面生成空的「雅思生词本」。
4. 在网页、PDF、Word 里拖选英文，松手即弹出黑色弹窗；点「☆ 收藏」保存到词库。

> **Windows SmartScreen 提示**：未做代码签名，首次运行可能弹出 SmartScreen。选择「更多信息 → 仍要运行」即可；个别杀毒软件可能误报，可添加信任。

## 使用说明

1. 启动后，在网页、PDF、Word 中用鼠标拖选英文：
   - 一个单词：查词典，显示音标、词性、中文释义；
   - 多个词的短语：查词典，查不到会自动按句子翻译；
   - 整句：直接显示中文翻译，可收藏到「句子.xlsx」。
2. 点「☆ 收藏」：单词存入 `词语.xlsx`，短语存入 `短语.xlsx`，句子存入 `句子.xlsx`。
3. 选中文字后按 `Ctrl+Alt+D` 也能取词。
4. 关闭弹窗：点弹窗外任意位置，或点右上角 `✕`。
5. 退出：右键托盘图标 → 退出。

### 同义替换怎么用

1. 取词得到第一个词（例如 `important`），点弹窗里的「同义替换」。
2. 弹窗消失，提示“请再取一个同义词”。
3. 再划选第二个词（例如 `crucial`），程序会把两个词及两边中文意思写入 `同义替换.xlsx`。
4. 表格字段：序号、同义词一、同义词意思、同义词二、同义词意思、收藏时间。
5. 词语、短语都可以作为同义词；单词的中文意思带词性（如 `adj. 重要的`），短语不带。

## 词库模板

默认词库位置：`D:\desktop\雅思生词本\`（可在配置中修改）。

| 文件 | 内容 | 字段 |
| --- | --- | --- |
| `词语.xlsx` | 单词 | 序号、单词、中文意思、收藏时间 |
| `短语.xlsx` | 短语 | 序号、短语、中文意思、收藏时间 |
| `句子.xlsx` | 整句 | 序号、英文句子、中文翻译、收藏时间 |
| `同义替换.xlsx` | 同义词 | 序号、同义词一、同义词意思、同义词二、同义词意思、收藏时间 |

- 仓库 `wordbook-template/` 目录提供上述 4 个**空白模板**，只含表头，不含任何历史词。
- 单词中文意思带词性（如 `n. 消费者，顾客`），短语不带词性。
- 每条只保留最多 3 个核心义项，去掉例句。
- 收藏时间只记日期（`2026-11-21`），不记具体时间点。
- 旧版本 Excel 第一次启动会自动迁移为上述列结构，原文件备份在词库目录的 `旧版备份` 文件夹；若迁移时文件被占用，会在下次启动或下次收藏时自动重试。

## 配置

配置文件位置：

```
%APPDATA%\IELTSPicker\config.json
```

| 键 | 说明 |
| --- | --- |
| `excel_dir` | 词库文件夹 |
| `auto_lookup` | 是否拖选后自动弹窗 |
| `restore_clipboard` | 取词后是否恢复原来的剪贴板内容 |
| `hotkey` | 快捷键，格式如 `Ctrl+Alt+D`、`Ctrl+Shift+W` |
| `popup_width` | 弹窗宽度（逻辑像素） |
| `welcomed` | 是否已显示过首次提示 |

改完配置后重启程序生效。

## 翻译接口说明

- **单词 / 短语**：有道词典网页 JSON 接口 `https://dict.youdao.com/jsonapi`，无需 API Key。
- **整句**：MyMemory 免费翻译接口 `https://api.mymemory.translated.net/get`（英译中），无需 API Key；句子结果本地缓存。
- 两者均为公开网页接口，**并非有道 / MyMemory 的付费官方 API**，稳定性和额度由对方控制；查过的内容会缓存在本地。
- 划词原理是模拟 `Ctrl+C` 读取选区，取词后会尽量恢复原剪贴板内容。

## 常见问题

- **点收藏没反应 / 提示 Excel/WPS 正在使用中**：对应词库文件被 Excel 或 WPS 打开，关掉后点「重试收藏」即可，不用重启程序。
- **快捷键没反应**：可能被其他软件占用，修改 `config.json` 里的 `hotkey`；或直接用鼠标划选。
- **某些窗口取不到词**：以管理员身份运行的窗口会拦截普通程序的模拟复制；需要时右键以管理员身份运行本程序。
- **句子翻译失败**：需要联网；MyMemory 公共接口有每日额度，失败时可稍后再试或先收藏单词。
- **杀毒软件拦截**：PyInstaller 打包的未签名 exe 可能被误报，添加信任即可。
