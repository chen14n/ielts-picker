雅思取词 使用说明
================

作者：周八拿铁
版本：2.0.0

1. 安装后，桌面和开始菜单会有「雅思取词」快捷方式，双击启动。
   右下角托盘会出现黑白「词」图标。

2. 在网页、PDF、Word 里，用鼠标拖选英文，松手后会弹出黑底弹窗。
   - 一个单词：查词典，显示音标、词性、中文释义
   - 多个词的短语：查词典；查不到会自动按句子翻译
   - 整句：直接显示中文翻译，可收藏到「句子.xlsx」

3. 点「☆ 收藏」：
   单词存入 词语.xlsx
   短语存入 短语.xlsx
   句子存入 句子.xlsx
   同一个内容不会重复收藏。
   单词的中文意思会带词性（如 n. / v. / adj.），短语不带。

4. 选中文字后按 Ctrl+Alt+D 也能取词。

5. 同义替换：
   取词后点「同义替换」，按提示再取一个词，
   两个词会自动写进「同义替换.xlsx」。
   表格只有同义词一、同义词二两组；单词会带词性，短语不带。

6. Excel 或 WPS 正开着词库文件时点收藏，会提示关闭后再点「重试收藏」，
   不需要重启程序。

7. 右键托盘里的「词」图标，可以暂停划词、打开词库文件夹、退出。

文档与模板：
- 安装目录下的「文档」文件夹有 README 和本说明。
- 「词库模板」文件夹是四个空白 Excel，只含表头，不含任何历史词。
- 首次启动会自动在桌面生成空的「雅思生词本」。

注意：
- 单文件 exe 请放在桌面/下载等较短路径运行；不要放进层级很深的同步目录。
- 第一次运行若出现 Windows SmartScreen，点「更多信息 → 仍要运行」。
- 单词/短语查有道词典，句子翻译用 MyMemory，均需联网；查过的会缓存。
- 旧版 Excel 第一次启动会自动换成新格式，原文件备份在「旧版备份」文件夹。
